# شواهد بررسی بازطراحی رابط آگاه

تاریخ: ۲۰۲۶/۱۱/۲۲ — دامنه: نسخهٔ Android 0.4.0-ui-rc1. این گزارش فقط دامنهٔ آزمون‌های اجراشده را تأیید می‌کند.

| بررسی | نتیجه |
|---|---|
| آزمون‌های پایهٔ مقدار دقیق، پاسخ API و ساخت فرم | ۹ موفق، صفر شکست |
| کنتراست دو پوسته | یک آزمون با ۱۶ بررسی؛ نسبت متن به زمینهٔ سطوح معنایی حداقل ۴٫۵ به ۱ |
| صفحهٔ ورود واقعی و نمایش/پنهان‌سازی گذرواژه | موفق؛ دکمهٔ ورود برای ورودی خالی غیرفعال و پس از تکمیل فعال است |
| قلم ۱۵۰٪ و شکستن سطر دکمه‌ها | موفق در عرض ۳۶۰dp؛ دکمه‌های خروجی هم‌پوشانی ندارند |
| تبلت افقی ۸۰۰×۶۰۰dp | موفق؛ فرم در مرکز و با عرض محدود است و دکمه با اسکرول قابل دسترسی است |
| اجزای واقعی داشبورد در تبلت | موفق؛ کارت مبلغ و بخش‌های عملیاتی با دادهٔ ساختگی آزمون رندر شدند |
| فرم باریک ۳۲۰dp، قلم ۱۵۰٪، خطای فیلد و انتخاب | موفق؛ ارتفاع هدف لمس سطر انتخاب حداقل ۴۸dp |
| ثبت و بررسی تصویر | هفت تصویر واقعیِ رندر Compose ذخیره و نمونه‌های ورود روشن/تیره، تبلت، فرم و قلم بزرگ بازبینی شدند |

مجموع: **۱۵ آزمون موفق، صفر شکست و صفر مورد نادیده‌گرفته‌شده**. شواهد XML و JSON در `ui-evidence/` هستند. تصاویر در `ui-previews/` و توضیح آن‌ها در `UI-PREVIEWS.md` قرار دارند.

رندر و آزمون تعامل با Robolectric 4.14.1، Android API 28 و موتور گرافیک native روی JVM انجام شد؛ آزمون روی گوشی فیزیکی یا شبیه‌ساز کامل اندروید محسوب نمی‌شود. صفحهٔ ورود مستقیماً از AgahApp و بدون سرور اجرا شد؛ نمونهٔ داشبورد و فرم، اجزای واقعی اپ با دادهٔ آزمون‌اند، نه ادعای ورود به حساب زنده. پیام قطع ارتباط در تصاویر ورود ناشی از شبکهٔ محیط آزمون است.

## بررسی ساخت و انتشار

نتیجهٔ نهایی ساخت، lint، نسخه و امضا در `ui-evidence/build-summary.json` ثبت شده است. گواهی توسعهٔ این APK همان گواهی نسخه‌های قبلی است؛ امضای تجاری/فروشگاهی مالک نیست. نسخهٔ قبلی RC1 و گزارش آن تغییر داده نشده‌اند.

## پذیرش روی گوشی واقعی

ورود و انتخاب شرکت/سال، بازکردن ۹ بخش، جست‌وجو، فرم بلند و صفحه‌کلید، چرخش، تغییر قلم، حالت روشن/تیره، بازگشت و تأیید خروج از فرم، ثبت با مجوز، دریافت PDF/CSV، انتخاب فایل، دوربین و خواندن با TalkBack روی گوشی مقصد بررسی شوند. تأیید کامل دسترس‌پذیری، تمام مدل‌های دستگاه و آزمون کامل مالیِ نسخهٔ نصب‌شده ادعا نمی‌شود. محدودیت‌های پذیرش RC1 تا اجرای آزمون مربوط باقی هستند.
