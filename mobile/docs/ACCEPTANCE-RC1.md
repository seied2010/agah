# گزارش پذیرش نامزد اندروید 0.3.0-rc1

تاریخ: ۲۰۲۶/۱۱/۲۱. محیط آزمایش سرور مستقل از سایت اصلی است: WordPress / PHP 8.3 / MariaDB 10.11.

| بررسی | نتیجهٔ مستند |
|---|---|
| API، مالی، مجوز، احراز هویت، خروجی و بازیابی | ۱۵۵ کنترل موفق؛ تفکیک و خروجی در پوشهٔ evidence |
| آزمون واحد اندروید | ۹ موفق، صفر شکست و صفر نادیده‌گرفته‌شده |
| Android Lint | صفر خطا، ۱۴ هشدار؛ شرح در گزارش امنیت |
| ساخت APK پذیرش | موفق، نسخهٔ 0.3.0-rc1-acceptance، versionCode=4 |
| امضا و Manifest | امضای توسعهٔ قبلی معتبر؛ backup و HTTP غیرفعال، debuggable فعال نیست |
| PDF فارسی سند و فاکتور | فایل واقعی تولید و تصویر آن بررسی شد؛ امضاهای سند موجود است |
| آزمون دستگاه روی آخرین تغییرات | در حال بررسی؛ شکست‌های قبلی شبیه‌ساز پیش از اجرای آزمون و ناشی از سرویس نصب اندروید بودند |
| آزمون دستگاه روی سورس قبلی | ۱۲ آزمون موفق؛ این نتیجه جایگزین آزمون آخرین تغییرات نیست |
| گوشی واقعی / دوربین / سرور مقصد | انجام نشده |
| پایگاه برخط آسیب‌پذیری وابستگی‌ها | دسترسی مسدود؛ تأیید امنیت وابستگی‌ها صادر نشده |

این خروجی **نامزد پذیرش** است و تأیید نهایی اجرای دستگاه یا انتشار فروشگاهی نیست. امضای مالک برای انتشار فروشگاهی هنوز فراهم نشده است. آزمون نسخهٔ غیرقابل‌دیباگ، قلم بزرگ و اندازه‌های مختلف دستگاه در فهرست باقی‌مانده قرار دارند. هیچ تغییری روی سایت اصلی انجام نشده است.

شاهدهای قابل بازبینی: `evidence/summary.json`، لاگ‌های کنترل سرور و سورس آزمون‌ها در `mobile-backend/tests` و `mobile/app/src/androidTest`.
