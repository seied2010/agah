# بررسی امنیت نسخهٔ پذیرش اندروید

دامنه: اپ بومی، افزونهٔ همراه و تغییرات محدود هستهٔ آنلاین؛ آزمون‌ها روی محیط جداگانه انجام شده‌اند. این گزارش گواهی افتا، تضمین نبود آسیب‌پذیری یا تأیید امنیت سرور اصلی نیست.

## کنترل‌های بررسی‌شده

| موضوع | شاهد |
|---|---|
| ورود و دومرحله‌ای | آزمون HTTP گذرواژهٔ نادرست، عامل دوم مفقود/نادرست، TOTP واقعی، منع تکرار و مصرف یک‌بارهٔ بازیابی |
| نشست | چرخش یک‌باره، خروج، بی‌اعتباری پس از تغییر امنیت، نگهداری رمز‌شدهٔ تمدید با Keystore و نبود ذخیرهٔ گذرواژه |
| شرکت و مجوز | جداسازی شرکت و فایل، نقش مشاهده‌گر، سقف شرکت و محدودیت شخصی، حالت خاموش و کنترل دوبارهٔ نوشتن زیر قفل |
| صحت مالی | اعداد صحیح مقیاس‌شده، رد float/سرریز، تراکنش هسته، کلید عملیات، نسخهٔ ویرایش و دورهٔ بسته |
| پاسخ نامشخص | عدم تکرار خودکار ثبت مالی، رسید مستقل از payload و مالک/سرور، مانع لغو دیررس و اعتبارسنجی رسید کامل |
| ورودی و خروجی | DTO محدود، پارامتر مسیر غیرقابل جایگزینی، جلوگیری از فرمول در CSV، HTML escape و پاسخ خصوصی بدون کش |
| فایل | MIME/محتوای مجاز، سقف حجم، دسترسی به هدف، SHA-256، نبود URL عمومی و اشتراک با مجوز موقت |
| بازیابی | آزمون واقعی بازیابی شرکت و همهٔ اطلاعات: لغو نشست، کاهش نوشتن به نمایش و حفظ مانع درخواست قدیمی |
| حریم دستگاه | پنجرهٔ امن، منع بکاپ/انتقال داده، نبود پایگاه دادهٔ مالی آفلاین و حذف فایل موقت هنگام خروج |
| لاگ | لاگ اختصاصی API شامل کلاس خطا و شناسهٔ پیگیری است؛ توکن، گذرواژه، بدنهٔ مالی و SQL در آن چاپ نمی‌شود. لاگ تشخیصی اندروید فقط در debug فعال است. |

بستهٔ نصب افزونه، اسکریپت‌های آزمون و حساب‌های ساختگی را ندارد. کد آزمون فقط محیط `local` را می‌پذیرد. فایل‌های کلید امضا، تنظیمات محلی و `.env` در بستهٔ سورس و مخزن عمومی قرار نمی‌گیرند.

## محدودیت‌ها و شرایط انتشار

- کتابخانهٔ PDF یعنی mPDF تحت GPL-2.0-only است؛ سازگاری مجوز بسته با مدل توزیع تجاری مالک باید بررسی شود. مجوز کد مالک در این کار تغییر داده نشده است.

- پایگاه‌های برخط آسیب‌پذیری وابستگی‌ها در محیط ساخت با محدودیت دسترسی روبه‌رو شده‌اند؛ پاک‌بودن وابستگی‌ها از این نظر تأیید نشده است.
- گواهی امضای نسخهٔ پذیرش همان گواهی توسعهٔ تحویل‌های قبلی است. کلید انتشار متعلق به مالک و انتشار فروشگاهی هنوز پیکربندی نشده‌اند؛ سورس، پیکربندی امن دریافت کلید از محیط را دارد.
- دستگاه فیزیکی، دوربین واقعی، تنظیمات WAF/TLS/بکاپ و ظرفیت سرور اصلی باید در پذیرش عملیاتی بررسی شوند. داده‌های زندهٔ سایت در این آزمون‌ها استفاده نشده‌اند.
- APK از TLS استاندارد سیستم استفاده می‌کند؛ روت یا آلودگی سیستم‌عامل و نسخه‌های ذخیره‌شده توسط برنامهٔ مقصد اشتراک‌گذاری، خارج از کنترل اپ هستند.
- بررسی ایستا بدون خطای مسدودکننده گذشت. هشدارهای باقی‌مانده شامل پیشنهاد KTX، دقت مسیر آیکون و commit هم‌زمان تنظیمات است؛ رسید عملیات باید پیش از ارسال مالی به‌صورت پایدار نوشته شود.

نتیجه: پذیرش آزمایشی مشروط به شواهد اجرای بسته؛ تأیید انتشار عمومی منوط به امضای مالک، بررسی وابستگی‌ها و پذیرش روی دستگاه و سرور مقصد است.
