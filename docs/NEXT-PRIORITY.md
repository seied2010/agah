# اولویت بعد از اصلاحات جاری

دستور کاربر در ۲۲ نوامبر ۲۰۲۶: پس از تحویل اصلاحات فعلی UI/UX و حذف فاکتور با دسترسی قابل‌تفویض، اولویت توسعهٔ بعدی **جداسازی دامنه‌ها** است. در پایان کار جاری یادآوری شود. پیش از پذیرش توسعهٔ تازه، این اولویت یادآوری و اجرای آن مطرح شود؛ اگر کاربر صریحاً اولویت را عوض کرد، دستور تازه ملاک است.

تا دستور صریح شروع مهاجرت، هیچ تغییری در دامنه، DNS، نصب‌ها، دادهٔ مالی، ورود، اشتراک یا نشانی API اجرا نشود. ثبت این یادداشت مجوز اجرای مهاجرت نیست.

طرح مورد بحث: دو نصب و پایگاه دادهٔ مستقل؛ `idpa.ir` برای معرفی، وبلاگ، فروش و پرداخت، و `soft.idpa.ir` فقط برای حسابداری. تأیید پرداخت در سرور، فعال‌سازی اشتراک با API امن، ورود با کد کوتاه‌عمر و یک‌بارمصرف. آماده‌سازی و آزمون در محیط جدا، انتقال نهایی با توقف کوتاه ثبت، و امکان بازگشت.

برآورد اولیه: ۵۰ تا ۹۰ هزار توکن و ۶ تا ۱۲ ساعت کار فعال، جدا از تنظیم هاست و پذیرش؛ پس از بررسی ورود یکپارچه، اشتراک، فایل‌ها و API دقیق‌تر شود. با دستور اجرای مهاجرت، اثر آن بر دسکتاپ و اندروید بررسی و تغییرات لازم نیز اعمال شود. دسکتاپ فعلی پایگاه دادهٔ مستقل و محلی دارد.
