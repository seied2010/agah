# شواهد بررسی خروجی‌های دسکتاپ و اندروید

دامنه: ERP وب 0.28.0-alpha1 ثابت، دسکتاپ محلی 0.2.0 و اپ آنلاین 0.5.0-business-rc1 با API 0.4.0-rc1.

| آزمون | نتیجه |
|---|---|
| دسکتاپ: HTTP در شبکهٔ Docker داخلی بدون اینترنت | ۱۳ کنترل موفق، شامل پشتیبان رمزگذاری‌شده و ورود سریع/AJAX محلی |
| دسکتاپ: سند آزمایشی و راه‌اندازی تکراری | سند و دو ردیف و مبلغ حفظ شدند |
| اسکریپت نصب و به‌روزرسانی دسکتاپ | هر دو با parser پاورشل لینوکس بدون خطای نحوی |
| امکانات جدید API موبایل | ۲۲ کنترل موفق: قیمت/انبار/مجوز، تسویهٔ ترکیبی اتمیک، تکرارپذیری امن، برگشت کامل در بیش‌پرداخت، قالب‌ها و اندازه/هش PDF |
| رگرسیون مالی API | ۱۴ کنترل موفق، شامل صدور قدیمی بدون تسویه و گزارش‌ها |
| رگرسیون امنیت API | ۲۳ کنترل موفق، شامل جداسازی شرکت/فایل، نقش مشاهده‌گر، DTO محدود و خروجی‌ها |
| واحد و رندر/تعامل اندروید روی JVM | ۲۱ آزمون موفق، صفر شکست/خطا/نادیده‌گرفته‌شده؛ شامل مقدار دقیق، ادغام اسکن، حفظ قیمت دستی، تسویه، قلم بزرگ و حفظ اطلاعات پس از رد مجوز |

بررسی JVM با Robolectric/API 28 و رندر native انجام می‌شود و آزمون اجرای APK روی گوشی نیست. آزمون Linux/PHP/MariaDB بستهٔ محلی، اجرای باینری ویندوز نیست. نصب/به‌روزرسانی Windows PowerShell 5.1، گوشی فیزیکی، بارکدخوان و چاپگر واقعی هنوز تأیید نشده‌اند.

ساخت نهایی APK موفق، lint بدون خطا و امضای توسعهٔ قبلی معتبر است. نتیجه و شواهد تفصیلی در `cross-platform-evidence/` ثبت شده‌اند. بستهٔ دسکتاپ از باینری‌های تأیید هش‌شدهٔ تحویل قبلی استفاده می‌کند؛ هستهٔ ERP آن با سورس وب تطبیق داده شده است. هیچ اطلاعات واقعی مشتری در بسته‌ها یا شواهد قرار نگرفته است.
