# بازبینی تحویل 0.28.1-ux1

| مورد | نتیجه |
|---|---|
| دامنه | رابط وب/هستهٔ مشترک، حذف فاکتور و تفویض دسترسی؛ بدون مهاجرت دامنه یا تغییر کد اپ بومی |
| رابط | ۳۷ سناریوی مرورگر، شامل ۱۵ مسیر در ۶ عرض؛ ۱۵ کنترل تکمیلی کارت موبایل و پیش‌نمایش فاکتور |
| حذف مالی | ۳۷ کنترل سرویس واقعی؛ برگشت دقیق مانده و موجودی، چک و تسویه، منع عملیات جزئی و دسترسی نامعتبر |
| حذف از رابط | ۱۶ کنترل مرورگر برای مجوز، انصراف، CSRF، نسخه، تکرار درخواست و بایگانی |
| دسترس‌پذیری | در ۲۴ حالت بررسی‌شده، صفر تخلف خودکار از قواعد انتخابی axe؛ پذیرش انسانی انجام نشده |
| رگرسیون | ۱۶ کنترل ورود سریع، ۱۳ کنترل تسویه/چهار قالب PDF، ۲۰۱ فایل PHP و چهار فایل JavaScript بدون خطای نحوی |
| پشتیبان | بازیابی واقعی فایل شرکت از نسخهٔ قبلی ۲۱ پس از ارتقا به ۲۲؛ ۱۰ کنترل بازیابی فعلی شرکت/کل نصب و ابطال نشست/عملیات قدیمی |
| محلی | ۱۳ کنترل HTTP بدون شبکهٔ خارجی، ماندگاری سند، تطبیق فایل هسته و نحو PowerShell؛ اجرای نصب واقعی ویندوز انجام نشده |
| بسته | ZIP و SHA256 و مانيفست فایل‌ها؛ باینری‌های محیط محلی همان نسخهٔ قبلی هستند |

شواهد در `docs/ux-0281-evidence/` و روش و حدود استفاده در `docs/UX-0281-FA.md` است. این خروجی روی سایت اصلی مستقر نشده و APK جدید ندارد. تکمیل صندوق یک‌صفحه‌ای، نیازهای حقوق و دستمزد و پذیرش کاربر/تجهیزات به‌عنوان کار انجام‌شده معرفی نمی‌شود.

**نتیجه: آمادهٔ تحویل آزمایشی، مشروط به پذیرش روی ویندوز/تجهیزات واقعی و آزمون محیط مقصد پیش از بهره‌برداری اصلی.**

پس از تحویل، اولویت بعدی مطابق دستور کاربر، جداسازی دامنه‌هاست و تا فرمان صریح شروع، اجرا نمی‌شود.
