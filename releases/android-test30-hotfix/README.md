# اصلاحیهٔ APK آزمایشی ۳۰٪ — 0.1.1-test30

این APK را روی نسخهٔ آزمایشی قبلی نصب کنید؛ کلید امضا یکسان است. این فایل نسخهٔ نهایی پروژه نیست.

- ثبت موفق، پیش از تازه‌سازی فهرست، فرم را می‌بندد. خرابی دریافت فهرست باعث فعال‌شدن دوبارهٔ فرمِ ثبت‌شده نمی‌شود.
- پاسخ ناقص یا خطای ناشناختهٔ واسط شبکه، موفقیت یا شکست قطعی عملیات فرض نمی‌شود؛ رسید برای استعلام باقی می‌ماند.
- پس از تأیید رسید عملیات نامشخص نیز فرم قبلی دوباره قابل ارسال نمی‌شود.
- دو آزمون مخصوص این خطاها روی اندروید و شش آزمون واحد موفق شده‌اند. بررسی مسیر کامل صفحات و قابلیت‌های جدید ادامه دارد.

برای آزمون همان امکانات قبلی، همان افزونهٔ API بستهٔ ۳۰٪ کافی است. تکمیل و تحویل یکپارچهٔ امکانات جدید و تغییرات سرور در خروجی نهایی انجام می‌شود.
