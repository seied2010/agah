# نمونهٔ اولیهٔ اجرای محلی ویندوز — 0.1.0

این ZIP شامل برنامهٔ آگاه، وردپرس، PHP و MariaDB مخصوص ویندوز x64، DLLهای موردنیاز و اسکریپت نصب/اجرا/توقف است. فایل README-fa.html داخل آن راهنمای کامل فارسی را دارد.

## مرز تحویل

این نسخه یک پوستهٔ اجرای محلیِ آزمایشی است و با نصب‌کنندهٔ CMD/PowerShell نصب می‌شود؛ نصب‌کنندهٔ EXE امضاشده، پنجرهٔ اختصاصی دسکتاپ و لایسنس تجاری ندارد. مرورگر موجود ویندوز رابط برنامه را روی http://127.0.0.1:18817 نمایش می‌دهد. نسخهٔ تجاری و آمادهٔ بهره‌برداری حساس نیست.

باینری‌های ویندوز در این محیط لینوکسی اجرا نشده‌اند. بنابراین نصب واقعی ویندوز ۱۰/۱۱، رفتار مسیرها، خاموش‌کردن/اجرای مجدد باینری‌های ویندوز، چاپ و تعامل با آنتی‌ویروس هنوز نیازمند آزمون روی ویندوز واقعی‌اند. بسته با عنوان «نصب ویندوز تأییدشده» ارائه نمی‌شود.

## موارد موجود

- نصب در %LOCALAPPDATA%\AgahLocalPrototype بدون دانلود در زمان نصب و بدون ثبت Windows Service.
- پایگاه دادهٔ محلی روی 127.0.0.1:33417 و برنامه روی 127.0.0.1:18817؛ هیچ‌کدام برای شبکهٔ عمومی bind نمی‌شوند.
- حساب اولیهٔ agah با گذرواژهٔ تصادفی و کلید رمزنگاری مستقل برای هر نصب. رمز اولیه فقط در فایل محلی FIRST-LOGIN.txt نمایش داده می‌شود؛ پس از تغییر رمز، آن فایل حذف شود.
- ایجاد شرکت محلی آزمایشی، میان‌بر دسکتاپ و فرمان Stop.cmd برای توقف.
- توقف عملیات اینترنتی وردپرس و شبکهٔ بیرونی برنامه در یک MU-plugin جداگانهٔ مخصوص بسته. ایمیل، پیامک، مؤدیان، اتصال فروشگاه و دریافت به‌روزرسانی اینترنتی در این نمونه کار نمی‌کنند.
- داده‌ها، کلیدها و پیوست‌ها روی همان رایانه هستند. پس از توقف، کل پوشهٔ نصب برای بازگردانی در همان مسیر/حساب ویندوز کپی شود. فقط db کافی نیست.
- کد آگاه 0.27.5-alpha و قالب 3.1.1-alpha بدون تغییر و با تطبیق تک‌تک هش فایل‌ها کپی شدند. فایل تنظیمات نصب جدید و راه‌انداز محلی جداگانه‌اند.

## آزمون‌های انجام‌شده

- ۱۱ کنترل HTTP محلی در شبکهٔ Docker داخلی بدون دسترسی بیرونی: صفحهٔ ورود، محدودیت CSP، رد Host بیگانه، ورود مدیر، داشبورد، منابع بدون میزبان خارجی، فرم پشتیبان، دانلود پشتیبان رمزگذاری‌شده، مسدودشدن HTTP بیرونی، نبود شرکت تکراری پس از راه‌اندازی مجدد و سلامت کلیدهای خارجی: موفق.
- ایجاد سند پیش‌نویس و حفظ دو ردیف و مبلغ آن پس از راه‌اندازی مجدد: موفق.
- تحلیل نحوی سه اسکریپت PowerShell با PowerShell 7.4.6 لینوکس: موفق؛ معادل اجرای آن‌ها روی Windows PowerShell 5.1 نیست.
- بررسی واردات باینری ۳۱ فایل x64 و وابستگی‌هایشان: وابستگی غیراستاندارد مفقود پیدا نشد؛ معادل آزمون اجرایی ویندوز نیست.
- هش آرشیوهای PHP/MariaDB با SHA256 منتشرشدهٔ ارائه‌دهنده تطبیق داده شد.
- ZIP سالم است و هیچ پایگاه دادهٔ آزمون، گذرواژهٔ آماده یا اطلاعات واقعی مشتری داخل آن نیست.
